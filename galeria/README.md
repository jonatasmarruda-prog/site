# Galeria dos Trilheiros

Galeria pós-passeio dos Trilheiros de Rondonópolis.

- Upload e otimização de fotos do celular (incluindo HEIC via conversão no navegador)
- Nome, passeio e descrição da experiência
- Legenda automática para redes sociais
- Moderação automática no navegador e no servidor
- Bloqueio de palavrões, ofensas e frases negativas/depreciativas
- Galeria pública com busca, filtro por passeio e compartilhamento
- Armazenamento com Netlify Blobs

O código pode ficar no GitHub, mas a versão multiusuário deve ser publicada no Netlify por usar Functions + Blobs.
